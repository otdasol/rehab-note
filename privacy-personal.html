개인판 · 시행일: [시행일]

요약 — Rehab노트(개인판)는 어떤 정보도 운영자에게 보내지 않습니다. 앱에는 인터넷 권한과 마이크 권한이 없으며, AI 기능이 없습니다. 모든 기록은 사용자의 휴대폰 안에만 있습니다.

1. 운영자가 수집하는 정보

없습니다. 앱은 회원가입·로그인·서버·분석 도구·광고를 쓰지 않으며, 운영자는 사용자의 기록이나 사용 내역을 받거나 볼 수 없습니다.

2. 휴대폰 안에만 저장되는 정보

치료 일정, 환자 표시(A, B 등), 진단명, 메모, 치료 기록, 평가 점수, 목표, 보고서, 설정은 사용자의 휴대폰 안 앱 저장 공간에만 저장됩니다. 앱을 삭제하면 함께 지워집니다.

앱은 환자의 이름·등록번호·연락처를 입력받지 않으며, 사용자에게도 입력하지 않도록 안내합니다.

사용자가 직접 만든 백업 파일은 사용자가 정한 비밀번호로 암호화되며, 사용자가 고른 위치에만 저장됩니다. 운영자는 이 파일과 비밀번호를 알 수 없습니다.

3. 휴대폰 권한

  • 생체 인증(지문 등): 앱 잠금 해제에만 씁니다. 지문 정보는 앱에 전달되지 않습니다.
  • 인터넷·마이크·위치·연락처 권한은 요청하지 않습니다.

4. 사용자가 직접 복사·저장하는 경우

복사한 기록을 다른 앱(EMR 등)에 붙여 넣거나 백업 파일을 저장하는 것은 사용자의 선택이며, 그 이후의 처리는 해당 앱·서비스와 근무 기관의 정책을 따릅니다. 근무 기관의 개인정보 보호 지침을 함께 지켜 주세요.

5. 사용자의 권리

  • 앱 안의 기록은 앱의 '오래된 기록 정리', 앱 데이터 삭제 또는 앱 삭제로 언제든 지울 수 있습니다.
  • 운영자는 기록을 갖고 있지 않으므로, 기록의 열람·삭제는 사용자의 휴대폰에서 직접 하시면 됩니다.

6. 안전성 확보 조치

  • 앱 잠금(PIN·지문)과 암호화 백업을 제공합니다.
  • 휴대폰 자동 백업(클라우드)에 앱 기록이 포함되지 않도록 설정했습니다.
